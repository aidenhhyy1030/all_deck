模型层在快速商品化，模型公司不向下游迁移、就只能做 token 销售渠道

价格塌方是结构性的、是不可逆的
  • 前沿模型平均输出价格指数 2023/3 至今从 100 降到 5.5，降幅 94.5%。
  • Epoch AI 测算推理价格年化下降中位 50×，2024/1 后加速至 200×；达到 GPT-4 级科学问答的成本每年降约 40×。
  • GPT-4 早期约每百万输入 token \$30，GPT-4o 同等能力降至 \$2.5，约三年内 12× 降幅。
  • DeepSeek R1 以 o1 级能力按 1/27 价格 供给（输入 \$0.55、输出 \$2.19，对应 o1 的 \$15 / \$60）。
价值集中在曲线两端，模型层夹在中间被挤压
  • 上游硬件算力（Nvidia、Broadcom、TSMC）和下游最后一公里捕获最多价值。
  • 开放权重把前沿能力差距压缩到 月度级，定价权与毛利同步流失。
  • 不拥有最后一公里落地能力的模型公司，最终只是 token 销售渠道。
向下游迁移是理性的利润再定位
  • 服务式部署贴近真实业务，客户黏性高，可绑定多年合约和消费量。
  • 代价是与 SI/咨询、Palantir、自家 API 应用层生态正面竞争（P10 详谈）。
  • OpenAI 与 Anthropic 都已下注，模型公司不动就是被动等利润蒸发。

单笔合同算得过来，规模化兑现要靠产品化 — Palantir 用 19 年证明了路径

单笔 FDE engagement 三情景
情景合同收入团队全成本毛利说明
保守\$50 万3 人 FDE\$90 万为负靠跨项目复用或低薪交付
中性\$150 万4 人\$120 万约 20%并行 2 个项目才稳定为正
乐观\$300 万4 人\$160 万约 47%养得起 \$30 万 FDE 的下限
中性 → 乐观区间是 JV 必须落到的位置
放大到 JV 层：兑现保底难度极高
  • 覆盖 \$40 亿资本的 17.5% = 每年 \$7 亿纯回报。
  • 按 15% 营业利润率（Accenture 14.7%、Globant 15%）倒推需 \$47 亿年收入。
  • 单笔均价 \$150 万 → 约 3100 个并行 engagement，数千 FDE，远超 Tomoro 150 人起点 — 需多轮并购堆人头。
  • 17.5% 更像 OpenAI 的战略担保，而非 JV 现金流自然结果。
Palantir 是唯一走通软件毛利的样本：路径漫长但可达
  • 把 FDE 做成 80%+ 软件毛利，毛利从 78% 抬到 82%；营业利润率 2025 才约 23%。
  • 亏损约 19 年（2003–2022），产品化用了近 20 年。

关系驱动：采购由客情关系决定，产品力和 ROI 不是关键项
  • 用户更在意客情关系，而不是产品本身好不好 — 中国 B 端二三十年历史遗留。

  • 全平台改造在中国硬推容易失败：缺数字化基础 + 人事阻力 + 文化对自上而下大变革排斥。

  • 存量（接补底座订单）：用友、金蝶（中小财务云市占第一）、神州数码、东软、中软国际、软通动力、太极股份、中国软件。
