动机 · 为什么双方都要做
这是一笔"互相帮忙"的结构性交易。

PE 缺

一鱼两吃：既参与最 hot 的 AI 资产；又用 JV 给自家 portfolio 提效 → 自己的 IRR 直接提升。

06 / 12
执行 · 核心论断
JV 在做的是 数字化 → AI 化，
不是 信息化 → AI 化 的三级跳。
信息化把流程搬进系统（ERP / 财务）→ 让数据被记录下来。
数字化系统打通、上云、API 化（SaaS / 数据中台）→ 让数据能流动、能被调用。
AI 化在前两层之上嵌入 agent → 让决策被机器做出。
→ 没有 API 就没有 agent 可调的工具，没有结构化数据就没有可检索的语料。AI 化必须站在数字化的肩膀上。

中国侧推演 · 真正的本土形态
中国版不会是 模型公司 × PE × Portfolio，
而是 模型公司 × 央企云 × 行业龙头。
PE 在中国为何不灵
Portfolio 控制力弱 · 没有 17.5% 工具 · 中型客户层断档
中国民营中型企业（$50M-$500M 营收）底座薄、付费习惯偏项目制、股东结构松散 → JV 推不动。
云厂商已在做"准 SI"
华为云 40+ 人驻场
腾讯云 10+ 行业 / 50+ 方案
已有客户关系 + 行业 know-how + 国资合规通关 — 但缺资本结构 + 估值故事。
推演结论中国版 "PE 角色"可能由 国资云 / 国家产业基金 / 地方政府引导基金扮演 — 类比中国电信 5G ToB 模式。
