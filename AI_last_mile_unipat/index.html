GC 全貌：管 \$430 亿、Creation Fund \$1.5B 专做 AI Rollup
  • General Catalyst，2000 年波士顿 Cambridge 创立，至今 26 年；2024 完成 \$80 亿 史上最大募资，2026 又募约 \$100 亿。
  • AUM > \$430 亿，团队 370–400 人，CEO Hemant Taneja，Chairman 前 Amex CEO Ken Chenault。
  • 代表案例：Stripe、Airbnb、HubSpot、Anthropic、Anduril、Helsing、Ramp、Canva。
  • Creation Fund \$1.5B 专做 AI Rollup — 收购控股的服务业公司，AI 改造后接管真实 P&L。
标杆案例：Crescendo 证明毛利上限，Long Lake 证明规模上限
  • Crescendo：AI 处理 90%+ Tier-1，毛利从 20–25% → 60–65%，ARR > \$1 亿，估值 \$5 亿。
  • Long Lake：30+ HOA 收购，不到 2 年做到 \$1 亿 EBITDA；2026 以 \$63 亿 收购 Amex GBT — 整体理论压力测试看 2027 财报。
  • GC 数字未经独立审计，operator 能力仍待 Amex GBT 验证。
但 \$1.5B 控股 + AUM 量级太重，模型公司需要一个更轻的版本
  • GC 这条路需要 \$1.5B Creation Fund + 控股运营能力，背后还有 \$430 亿 AUM 撑腰，是机构级解法。
  • 模型公司不可能也不必复制这个量级 — 但 GC 已经证明这块高地值得抢。

OpenAI 是杠杆扩张机器，Anthropic 是轻量咨询替代实验 — 同壳不同芯

OpenAI 杠杆版：用 17.5% 保底换 PE 现金，被算力账单逼出来
  • \$40 亿 PE + \$5 亿 OpenAI 现金（期权至 \$15 亿）→ 估值 \$10–14B，OpenAI 多数股权 + 超级投票权。
  • 17.5% / 5 年保底，PE 拿优先股优先于普通股 — 用极少现金撬动控制权。
  • 算力堆叠 8 年累计 \$1.4 万亿（下调到 2030 \$6000 亿）：Broadcom \$3500 亿 + Oracle \$3000 亿 + MSFT \$2500 亿 + Nvidia \$1000 亿 + AMD \$900 亿 + AWS \$380–1000 亿 + CoreWeave \$224 亿。
  • 缺口巨大：2025 收入 \$130–200 亿 vs 最高 \$3000 亿缺口（HSBC 估 2030 仍有 \$2070 亿）；2026 亏 \$140 亿、2029 累亏 \$1150 亿。
  • 兑付路径：IPO 股票（隐性可转债）或 token credit 抵债。
  • 本质：用极少现金 + 巨大杠杆 + 用未来对冲今天。
Anthropic 轻量版：服务 2026/10 IPO 叙事，无兜底
  • \$1.5B 承诺资本，无保底；创始档 \$1.05B 四方均衡（Blackstone/H&F/Anthropic 各 \$300M + Goldman \$150M），GA/Apollo/GIC/Sequoia 等补足。
  • 独立实体，资源嵌入（类 Palantir 模式）；领导团队含 Anthropic Applied AI 的 Garvan Doyle，Fractional AI 创始人 Chris Taylor/Eddie Siegel 留任，Blackstone Rodney Zemmel、H&F Tarim Wasim 参与。
  • 算力压力更小：TPU 100 万颗 2026 上线、超 1 吉瓦；AWS \$1000 亿/10 年、最高 5 吉瓦。
  • 收入覆盖好：年化 \$300 亿（2025 底 \$90 亿），一季度营收 \$4.8B — 不需要兜底。
  • 2026/10 IPO 是直接动因：上轮 G 轮估值 \$380B，5 月报道新一轮 pre-money 超 \$900B；把低毛利出表保软件毛利。
  • 本质：多方共担、不设兜底的咨询替代实验。
口头补充口头补充：差异根源在算力压力 — OpenAI 已签约束远超收入，Anthropic 收入对算力义务覆盖率明显优于 OpenAI。

  • Supercell（移动游戏）：1.1 亿用户的游戏内支持 agent，12 周上线，每日处理 GPT-4o 5 亿 token + 4o-mini 2 亿 token，工单成本降 90%、满意度升 20%、平均响应 7 秒

金融服务
  • Fidelity（资产管理）

Tomoro 团队画像：传统咨询出身的科技转型班底
  • 2023 年与 OpenAI 结盟成立，总部 爱丁堡 + 伦敦，亚太：墨尔本/悉尼/新加坡（亚太总部）。
  • 创始团队来自 Accenture / Mudano（2020 被 Accenture 收购）/ Lloyds / EY：Rishabh Sagar、Chris Spencer、Ed Broussard、Albert Phelps。
  • 约 150 FDE 整体并入 DeployCo，自创立起享 OpenAI 技术早期接入。

行业推断：OpenAI 的 JV 切的是消费级运营，不是重监管 B2B
  • 客户全部是高吞吐量 B2C 接触点 — 游戏内支持、航空客服、零售/物流前线。
  • 改造场景集中在 客户支持、内容生成、消费交互 — 正是 GPT-4o 多模态最强的场景。
  • OpenAI 不打算先做生命科学、铁路安全、PE 资管这种重监管深度活，先吃易复制、好规模化的消费级运营。
Tomoro 薪酬（UK 口径）：FDE 比模型公司自家工程师便宜 4–5×
  • AI 工程师平均 £90K（£57K–£98K），约 \$73K–\$125K。
  • Member of Technical Staff（伦敦）：base £100K + £10K = £110K（约 \$140K）。
  • Applied AI Solution Engineer：£70K–£90K + EMI 期权。
  • 对比 OpenAI 工程师中位 \$555K：FDE 单位成本只有自家研究员的 1/4 到 1/5 — 用 PE 现金养便宜 FDE 卖贵服务，是模式自洽的关键。

Part 5 · 代价 · Page 7

代价是渠道冲突 — 模型公司同时把合作方变成竞争对手

对 SI 与咨询：合作方变对手
  • SI 与咨询本来就是 OpenAI/Anthropic 的官方合作 + 培训渠道：Accenture、Deloitte、McKinsey、Capgemini、Bain
  • 且：McKinsey、Capgemini、Bain 同时出现在 DeployCo 投资财团里 — 不仅合作，还出钱投
  • 但：模型公司自建 FDE = 直接切数千亿美元实施市场，等于一边借渠道铺货、一边亲自下场抢单
  • 结果：Accenture FY25 GenAI 订单 \$5.9B 但股价从高点回落 42%，市场已经在定价反噬
对 Palantir 与应用生态
  • Palantir 既是客户也是竞争对手：AIP 平台调用 OpenAI/Anthropic API（客户关系），但 Palantir 的核心业务是 FDE 嵌入式部署 — 正是模型公司在复制的模式
  • 两家用自有模型 + FDE，从软件 + 服务两侧夹击 Palantir 的成名打法
  • 应用层焦虑：数千家建在 API 上的 startup 突然发现，自己的模型供应商正在变成自己的竞争对手
  • 纵向整合在加速：Anthropic 收购 Stainless（SDK 基础设施），平台向上下游扩张
渠道冲突不是 JV 设计缺陷，是模型公司向下游迁移的天然代价
本质：纵向整合带来的旧伙伴变新对手
  • 模型公司用 PE 合资 + FDE + 收购科技转型公司，直接占据原本属于 SI 与 Palantir 的位置。
  • 短期反噬：渠道伙伴合作积极性下降，应用层创业者对被吞噬的焦虑变实。
  • 长期赢面：模型公司同时控住模型、工具链、部署 — 完整价值捕获值得渠道冲突代价。
对 Unipat 的启示：渠道战略要先想清楚
  • 先决定要不要继续和 SI 合作 — 做 JV 必须接受和这些伙伴的部分关系反转。
  • 提前圈定应用层生态边界 — 哪些场景自己做、哪些留给生态。
  • 把 SDK / 工具链作为收编工具，而不是被对手抢先（参考 Anthropic 收购 Stainless）。

为什么红杉中国是 Unipat 在中国做 JV 的天然 PE 伙伴
  • Portfolio 规模对得上 Blackstone 那个位置：红杉中国 portfolio 覆盖消费、产业、医疗、SaaS、出海等多行业，提供现成的中国 mid-size enterprise 客户底盘。
  • 资本 + 运营 + 估值故事三位一体：完整对标美式 PE × 模型公司 JV — 这是中国 PE 里能给的最完整组合。
JV 结构建议：参考 OpenAI/Anthropic 模型，本土化执行

  • 红杉中国给：portfolio 客户聚合、外部现金、估值故事 — 一笔投入拿两份回报（AI 资产敞口 + portfolio 提效）。
