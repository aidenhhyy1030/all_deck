JV 是各取所需的结构交易，模型公司缺什么，PE 正好能给

模型公司缺，PE 能给
  • 2000+ portfolio companies 现成企业客户清单
  • 外部现金，补算力承诺与收入的缺口
  • 估值故事，把低毛利服务出表保 SaaS 倍数
  • 资产叙事，从 safety lab 转向华尔街看得懂的结构
⇄
PE 缺，模型公司能给
  • 最 hot 的 AI 资产敞口
  • portfolio 提效工具，直接抬高自家 IRR
  • 配置型回报（17.5% 保底正合 PE 味口）
  • 未来在 take-private/carve-out/buy-and-build 的 AI 落地话语权
JV 不是单纯股权投资，是双向补缺
基本面动因：C 端 + B 端 + 整体经营三层压力
  • C 端订阅增速放缓且 margin 低；B 端自建 enterprise sales team 周期太长。
  • 模型公司整体经营压力大，急需一条 12–18 个月可见结果的 enterprise 路径。
直接动因：IPO 在即，把低毛利打包出表
  • Anthropic 据报目标 2026/10 IPO，把低毛利服务塞进 JV 是直接动因。
  • OpenAI 在 IPO 之外引入外部现金，先锁定 enterprise revenue。
  • 路径：先在 PE portfolio 跑通 → 下放到所有 mid-size companies → 形成行业标杆。

OpenAI 是杠杆扩张机器，Anthropic 是轻量咨询替代实验 — 同壳不同芯

OpenAI 杠杆版：用 17.5% 保底换 PE 现金，被算力账单逼出来
  • \$40 亿 PE + \$5 亿 OpenAI 现金（期权至 \$15 亿）→ 估值 \$10–14B，OpenAI 多数股权 + 超级投票权。
  • 17.5% / 5 年保底，PE 拿优先股优先于普通股 — 用极少现金撬动控制权。
  • 算力堆叠 8 年累计 \$1.4 万亿（下调到 2030 \$6000 亿）：Broadcom \$3500 亿 + Oracle \$3000 亿 + MSFT \$2500 亿 + Nvidia \$1000 亿 + AMD \$900 亿 + AWS \$380–1000 亿 + CoreWeave \$224 亿。
  • 缺口巨大：2025 收入 \$130–200 亿 vs 最高 \$3000 亿缺口（HSBC 估 2030 仍有 \$2070 亿）；2026 亏 \$140 亿、2029 累亏 \$1150 亿。
  • 兑付路径：IPO 股票（隐性可转债）或 token credit 抵债。
  • 本质：用极少现金 + 巨大杠杆 + 用未来对冲今天。
Anthropic 轻量版：服务 2026/10 IPO 叙事，无兜底
  • \$1.5B 承诺资本，无保底；创始档 \$1.05B 四方均衡（Blackstone/H&F/Anthropic 各 \$300M + Goldman \$150M），GA/Apollo/GIC/Sequoia 等补足。
  • 独立实体，资源嵌入（类 Palantir 模式）；领导团队含 Anthropic Applied AI 的 Garvan Doyle，Fractional AI 创始人 Chris Taylor/Eddie Siegel 留任，Blackstone Rodney Zemmel、H&F Tarim Wasim 参与。
  • 算力压力更小：TPU 100 万颗 2026 上线、超 1 吉瓦；AWS \$1000 亿/10 年、最高 5 吉瓦。
  • 收入覆盖好：年化 \$300 亿（2025 底 \$90 亿），一季度营收 \$4.8B — 不需要兜底。
  • 2026/10 IPO 是直接动因：上轮 G 轮估值 \$380B，5 月报道新一轮 pre-money 超 \$900B；把低毛利出表保软件毛利。
  • 本质：多方共担、不设兜底的咨询替代实验。
口头补充口头补充：差异根源在算力压力 — OpenAI 已签约束远超收入，Anthropic 收入对算力义务覆盖率明显优于 OpenAI。

代价是渠道冲突 — 模型公司同时和 SI、Palantir、自家应用生态正面竞争

对 SI 与咨询
  • Accenture FY25 GenAI 订单 \$5.9B、相关收入 \$2.7B，但股价自高点回落 42%
  • OpenAI 自建 FDE 直接切数千亿美元实施市场
  • 悖论：McKinsey、Capgemini、Bain 既是 OpenAI 培训渠道、又在 DeployCo 投资财团里 — 既合作又被竞争
  • Deloitte、IBM 反应慢，且无模型授权与隐性补贴优势
对 Palantir 与自家应用生态
  • FDE 嵌入式部署正是 Palantir 成名模式，两家在复制并叠加自有模型，软件 + 服务两侧夹击
  • 数千家建在 OpenAI/Anthropic API 上的应用层公司，面临被自家模型公司 纵向整合吞噬 的风险
  • Anthropic 已收购 Stainless（SDK 基础设施） 等上下游，加剧应用层焦虑
  • Fractional AI 与 OpenAI 11 个月合作直接终止，是模型公司互抢落地团队的最新注脚
渠道冲突是必经的代价 — 不是 JV 设计缺陷，是向下游迁移的天然结果
本质：纵向整合带来的旧伙伴变新对手
  • 模型公司用 PE 合资 + FDE + 收购科技转型公司这套打法，直接占据原本属于 SI 与 Palantir 的位置。
  • 短期反噬：渠道伙伴合作积极性下降，应用层创业者对 被吞噬 的焦虑变实。
  • 长期赢面：模型公司同时控住模型、工具链、部署 — 完整价值捕获值得渠道冲突代价。
对 Unipat 的启示：渠道战略要先想清楚
  • 先决定要不要继续和 SI 合作 — 做 JV 必须接受和这些伙伴的部分关系反转。
  • 提前圈定应用层生态边界 — 哪些场景自己做、哪些留给生态。
  • 把 SDK / 工具链作为收编工具，而不是被对手抢先（参考 Anthropic 收购 Stainless）。

GC 全貌：管 \$430 亿、Creation Fund \$15B 专做 AI Rollup

  • AUM > \$430 亿，团队 370–400 人，CEO Hemant Taneja，Chairman 前 Amex CEO Ken Chenault。
  • 代表案例：Stripe、Airbnb、HubSpot、Anthropic、Anduril、Helsing、Ramp、Canva。
  • Creation Fund \$15B 专做 AI Rollup — 收购控股的服务业公司，AI 改造后接管真实 P&L。
标杆案例：Crescendo 证明毛利上限，Long Lake 证明规模上限

  • 改造深度越高、价值捕获越完整，但需要的资本和组织能力呈非线性上升。

中国驻场工程师典型案例库
时代公司模式教训
1990s–2000s用友 / 金蝶ERP 驻场实施客户化定制吞噬标准化，毛利从软件被压成项目

美式 JV-FDE 模型如不换打法，会重蹈以上每一条覆辙

  • 两头不靠：客户不完全信任驻场的人、工程师离自己老板又远。

  • 价值归属模糊：改造成果算客户的资产还是 JV 的资产，扯皮。
Unipat 必须直面的现实：FDE 复合人才几乎空白
  • 中国驻场工程师人头比美国多一个数量级，挖人不难；但单位人头客单价支撑不起 Palantir 级薪酬 — 招得到、养不起。
  • 真正稀缺的不是驻场经验，是 既懂模型又懂客户业务的复合型 FDE，国内几乎空白、需从零培养。

三方合资替代美式 PE × portfolio 结构
三方合资为什么比云厂商独立做或 PE 主导更优
  • 云厂商已在做准 SI（华为云 40+ 人/项目、腾讯云 50+ 解决方案、阿里云 Qwen 3 + agent 平台），但单独走缺资本结构 + 估值故事。
  • 中国 PE 的 portfolio 聚合、控制、命令权远不如 Blackstone，单独走推不动。
  • 三方合资补全：模型 + 客户聚合 + 资金 + 估值故事 + 合规 = 完整闭环。
单点切入是中国 AI 化的现实路径，不是整平台 transform
  • 全平台改造在中国硬推容易失败：缺数字化基础 + 人事阻力 + 文化对自上而下大变革排斥。
  • 单点切入三优势：人事阻力小 / ROI 显性化快 / 技术上踩在能力可及处（coding、设计已能明显提效）。
  • 投资视角：看标的有没有抓住一个 ROI 最硬、最快见效的单点，以及能否 沿这个点向全平台扩散。
数字化转型第二春已经在跑出来，存量 + 新势力都要看
  • 存量（接补底座订单）：用友、金蝶（中小财务云市占第一）、神州数码、东软、中软国际、软通动力、太极股份、中国软件。
  • 新势力（为 AI 而生的底座）：滴普科技（2025/10 港股上市，AI 级企业 OS）、第四范式、数势科技、衡石科技、PingCAP。
  • 关键卡点：数据资产化（2026 起部分制造业可入表）+ AI-readable 率 约 30% = 真正的瓶颈。
