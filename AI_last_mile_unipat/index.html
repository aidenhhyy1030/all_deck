OpenAI 与 Anthropic 同日宣布相同 JV 结构 — 杠杆机器 vs 轻量实验

OpenAI DeployCo
  • PE 财团 \$40 亿 + OpenAI 现金 \$5 亿 （期权至 \$15 亿）
  • 估值 \$10B–\$14B ，OpenAI 多数股权 + 超级投票权
  • 17.5% / 5 年保底 ，PE 拿优先股优先于普通股
  • TPG 领投 19 家：Advent、Bain、Brookfield、SoftBank、Goldman、Warburg、WCAS、McKinsey、Capgemini 等
⇄
Anthropic JV
  • \$1.5B 承诺资本，无保底
  • 创始档 \$1.05B：Blackstone / H&F / Anthropic 各 \$300M + Goldman \$150M
  • 独立实体，资源嵌入（类 Palantir 模式）
  • GA / Apollo / GIC / Sequoia / Leonard Green 等补足；治理含 Anthropic Applied AI 的 Garvan Doyle
同日、同结构、同量级对手方 = 行业共识，不是巧合
双向补缺：模型公司缺客户/现金/估值，PE 缺 AI 敞口/配置回报
  • 模型公司缺 ：2000+ portfolio 现成客户 + 外部现金（补算力缺口）+ 估值故事（低毛利出表保 SaaS 倍数）。
  • PE 缺 ：AI 资产敞口 + portfolio 提效抬 IRR + 17.5% 配置型回报 （正合 PE 味口）。
  • 直接动因 ：Anthropic 2026/10 IPO 在即；OpenAI 用 JV 锁定 enterprise revenue 应对算力账单。
OpenAI 杠杆版：被算力账单逼出来，用极少现金撬动控制权
  • 算力堆叠 8 年累计 \$1.4 万亿 （下调到 2030 \$6000 亿）：Broadcom \$3500 + Oracle \$3000 + MSFT \$2500 + Nvidia \$1000 + AMD \$900 + AWS \$380–1000 + CoreWeave \$224 亿。
  • 2025 收入 \$130–200 亿 vs \$3000 亿缺口 （HSBC 估 2030 仍有 \$2070 亿）；2026 亏 \$140 亿、2029 累亏 \$1150 亿。
  • 兑付路径： IPO 股票 （隐性可转债）或 token credit 抵债 — 用未来对冲今天。
Anthropic 轻量版：服务 2026/10 IPO 叙事，无兜底
  • 算力压力更小：TPU 100 万颗 / 1+ 吉瓦；AWS \$1000 亿/10 年 / 5 吉瓦。
  • 收入 年化 \$300 亿 覆盖好（2025 底 \$90 亿），一季度营收 \$4.8B。
  • G 轮估值 \$380B ，新一轮 pre-money 超 \$900B ；把低毛利出表保软件毛利撑 IPO 叙事。

  • 约 150 FDE 整体并入 DeployCo；收购 待监管批准 ，预计数月内完成。
服务交付：4 条服务线 + 8–12 周节奏，全栈而非纯外包
  • 业务战略 ：2 周交付 AI 路线图（高层咨询）。
  • 定制 AI 解决方案 ：通常 12 周进生产（核心业务）。
  • 企业 AI 基础设施 ：底层架构搭建。
  • 采用与推广培训 ：组织赋能。
  • 典型节奏：概念到上线 8–12 周 — 比传统 SI 项目快 3–5×。
  • 收购对价未披露 ；英国媒体口径 £29 亿是 OpenAI 在英综合投入， 不是 Tomoro 单笔价格 。
行业推断：OpenAI 的 JV 切的是消费级运营，不是重监管 B2B
  • 客户全部是高吞吐量 B2C 接触点 — 游戏内支持、航空客服、零售/物流前线。
  • 改造场景集中在 客户支持、内容生成、消费交互
  • 地理覆盖隐含战略 ：UK + EU + APAC，OpenAI 优先扩张非美西方市场。
  • OpenAI 不打算先做生命科学、铁路安全、PE 资管这种重监管深度活，先吃易复制、好规模化的消费级运营。

  • Member of Technical Staff（伦敦）：base £100K + £10K = £110K （约 \$140K）。

Part 5 · 代价 · Page 6

代价是渠道冲突 — 模型公司同时把合作方变成竞争对手

对 SI 与咨询：合作方变对手
  • SI 与咨询本来就是 OpenAI/Anthropic 的官方合作 + 培训渠道 ：Accenture、Deloitte、McKinsey、Capgemini、Bain
  • 且 ：McKinsey、Capgemini、Bain 同时出现在 DeployCo 投资财团里 — 不仅合作，还出钱投
  • 但 ：模型公司自建 FDE = 直接切数千亿美元实施市场，等于一边借渠道铺货、一边亲自下场抢单
  • 结果 ：Accenture FY25 GenAI 订单 \$5.9B 但股价从高点回落 42% ，市场已经在定价反噬
对 Palantir 与应用生态
  • Palantir 既是客户也是竞争对手 ：AIP 平台调用 OpenAI/Anthropic API（客户关系），但 Palantir 的核心业务是 FDE 嵌入式部署 — 正是模型公司在复制的模式
  • 两家用自有模型 + FDE，从软件 + 服务两侧夹击 Palantir 的成名打法
  • 应用层焦虑 ：数千家建在 API 上的 startup 突然发现，自己的模型供应商正在变成自己的竞争对手
  • 纵向整合在加速 ：Anthropic 收购 Stainless（SDK 基础设施） ，平台向上下游扩张
渠道冲突不是 JV 设计缺陷，是模型公司向下游迁移的天然代价
本质：纵向整合带来的旧伙伴变新对手
  • 模型公司用 PE 合资 + FDE + 收购科技转型公司， 直接占据原本属于 SI 与 Palantir 的位置 。
  • 短期反噬：渠道伙伴合作积极性下降，应用层创业者对被吞噬的焦虑变实。
  • 长期赢面：模型公司同时控住模型、工具链、部署 — 完整价值捕获值得渠道冲突代价。
